1. Executive Summary & Problem Context

Modern autonomous browser automation agents (such as OpenAI Operator, Gemini Auto Browse, and Claude Computer Use) present a severe structural security vulnerability: they capture unredacted full-screen viewport frames and transmit them to external cloud vision-language models (VLMs). This exposes plaintext credentials, government IDs (Aadhaar, PAN, SSN), confidential ISRO aerospace telemetry, and biometric facial data.

PrivyBrowse-X solves this by executing a deterministic, multi-modal perception, OCR, visual object detection, and zero-leakage blackout sanitization pipeline 100% on-device inside a Chrome Extension (Manifest V3). The cloud VLM receives only mathematically sanitized, tokenized context, while sensitive values are de-anonymized strictly on-device at the point of actuation.

2. Multi-Modal Perception & Privacy Engine Pipeline

Visual & Structural Perception Layer
  • OWL-ViT (Zero-Shot Vision): Quantized ONNX weights running on ONNX Runtime WASM SIMD / WebGPU for detecting physical credit cards, passports, and physical credentials in viewport images.
  • MediaPipe BlazeFace: 200KB TFLite model running in WASM for on-device biometric landmark and facial detection.
  • Tesseract OCR Engine: WASM worker extracting textual tokens from document scans and images with regex matching for Aadhaar, PAN, SSN, Credit Cards, IFSC, Email, and Phone numbers.
  • DOM Perception Tree: Real-time traversal of input tags, password fields, and aria attributes.
Decision & Safety Governance Layer
  • Spatial IoU Fusion: Merges DOM coordinates, visual bounding boxes, and OCR text into a Unified Perception State.
  • Local Qwen Reasoner (Ollama): Fine-tuned isro-privacy-qwen:latest resolves ambiguous and contextual elements.
  • Strict Invariant Matrix: Passwords, OTPs, PINs, CVV, and Private Keys are mathematically hard-locked to BLOCK (Omit & Blackout).
  • AES-256-GCM Vault: Stores credentials encrypted with PBKDF2; tokens are injected locally only at final DOM dispatch.

5. Technical Defense Sheet for Hackathon Jury

Q: How do you guarantee zero raw pixel leakage?

A: Viewport buffers captured via chrome.tabs.captureVisibleTab are piped strictly into an offscreen HTML5 canvas. Opaque blackout bounding boxes are stamped directly onto the pixel buffer before any export. The network communication layer has no memory pointer to the unredacted frame.

Q: Why combine fast rules with Local Qwen?

A: Fastpath deterministic rules process standard forms in <5ms. Local Qwen 1.5B is invoked exclusively for nuanced semantic ambiguity (e.g. public press release search vs confidential telemetry log query), maintaining high FPS while eliminating hallucinations.
