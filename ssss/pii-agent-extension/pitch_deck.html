Engineering Pragmatism & Q&A Defense

Demonstrating technical maturity through defensible design choices and known boundaries.

1. The Person-vs-Face Heuristic Proxy

Decision: Redacting the upper ~30% slice of detected person bounding boxes.
Defense: Standard ViT object detectors detect 80 COCO classes, not facial landmarks. Training a custom face detector from scratch would bloat model size. The 30% vertical proxy provides instant zero-latency face protection with zero additional weights.

2. Dual Runtime Architecture (WebGPU + WASM)

Decision: WebGPU primary with automated WASM fallback.
Defense: WebGPU support varies across older hardware or restricted evaluation laptops. Rather than failing or crashing, our extension automatically detects hardware support and gracefully falls back to WASM SIMD.

3. Separation of Concerns (Privacy vs Reasoning)

Decision: Local client enforces privacy; server handles heavy visual reasoning.
Defense: Running a full 70B VLM on-device is impossible on client hardware. Offloading sanitized-only context preserves 100% privacy while retaining state-of-the-art reasoning power.

4. Manifest V3 Offscreen Engine

Decision: Chrome Offscreen Document for WebGPU & Canvas.
Defense: MV3 Service Workers lack DOM and WebGPU APIs. Using Chrome's official chrome.offscreen API ensures 100% platform compliance without insecure workarounds.
