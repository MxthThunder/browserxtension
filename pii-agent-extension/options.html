    How Vault Tokens Work

    When the agent needs to fill a sensitive field — your email, say — it requests {{VAULT:contact.email}} from the server.

    The reasoning server never sees your actual email, only the token. The extension resolves it to the real value on-device, at the last millisecond before DOM injection.

    Zero-leakage: your data stays on-device, always.
