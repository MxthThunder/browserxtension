🤖 How Vault Tokens Work

When the agent needs to fill a sensitive field (e.g. your email), it requests {{VAULT:contact.email}} from the server.

The VLM server never sees your actual email — only the token. The extension resolves it to the real value on-device, at the last millisecond before DOM injection.
